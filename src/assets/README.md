# Assets Folder

This folder contains custom images for the portfolio website.

## Center Images (for home page slides)
- Upload your center images here with descriptive names like:
  - `center-introduction.png` - For Introduction slide
  - `center-history.png` - For History slide
  - `center-working-mechanism.png` - For Working Mechanism slide
  - `center-instrumentation.png` - For Instrumentation slide
  - `center-advantages.png` - For Advantages slide
  - `center-disadvantages.png` - For Disadvantages slide

## Floating Images (small images around center)
- Upload floating/thumbnail images with names like:
  - `float-introduction.png`
  - `float-history.png`
  - etc.

Once you upload your images, I'll update the code to use them!
